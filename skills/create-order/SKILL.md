# Create Order - ERP 訂單建立

## AI 行為指引

### 何時啟動此 Skill
- 用戶明確表達要「建立新訂單」的意圖
- 關鍵詞：建立訂單、下單、訂購、我要訂、建單、開訂單、幫我訂、order、新訂單
- 用戶提供了客戶名稱 + 品項資訊

### 何時不要啟動
- 用戶只是查詢訂單狀態（例如：「ORD-260123 的狀態？」）
- 用戶要修改已存在的訂單
- 用戶問價格但沒有要下單
- 對話中提到「訂」但不是要建立訂單（例如：「我訂閱了」「預訂時間」）
- 用戶要生成報價單/採購單/銷貨單 → 應啟動 generate-pdf

### 核心流程
```
解析用戶訊息 → 查詢 ERP 客戶 → 顯示確認 → 用戶確認 → 建立訂單
```

### AI 角色
- 呼叫 `createOrder(message, context, claudeApi)` 後，系統會自動處理整個流程
- AI 只需要把系統回傳的訊息傳給用戶
- 不需要手動呼叫 ERP API，index.js 已處理所有認證和 API 調用

## 互動模式

### 模式 A：一次提供完整資訊（主要模式）

用戶一句話提供客戶名 + 品項，系統解析後顯示確認：

```
📱 用戶：/order 王小明 A產品x2@500 B產品x1@300

🤖 系統：
✅ 訂單確認
━━━━━━━━━━━━━━━━
👤 客戶：王小明 (CUS0001)
📦 品項：
  • A產品 × 2 @ $500 = $1000
  • B產品 × 1 @ $300 = $300
💰 總額：$1300
📍 地址：台北市信義區
💳 付款：現金
━━━━━━━━━━━━━━━━
請回覆「確認」以建立訂單，或「取消」

📱 用戶：確認

🤖 系統：
✅ 訂單建立成功！
📋 訂單編號：ORD26ABCXYZ
👤 客戶：王小明
📦 品項：
  • A產品 × 2 @ $500
  • B產品 × 1 @ $300
💰 總額：$1300
⏱️ 狀態：待處理

💡 提示：如需報價單，請使用「生成報價單 ORD26ABCXYZ」
```

**確認指令：** confirm / yes / y / 是 / 確認
**取消指令：** cancel / no / n / 否 / 取消

### 模式 B：客戶不存在

系統查詢 ERP 找不到客戶時，提供三選一：

```
📱 用戶：/order 陳先生 C產品x3

🤖 系統：
找不到客戶「陳先生」

請選擇：
1️⃣ 建立新客戶「陳先生」
2️⃣ 重新輸入客戶名稱
3️⃣ 取消

請回覆 1、2 或 3
```

- 選 1：系統直接建立新客戶（使用訊息中已有的電話，不會額外詢問），然後繼續訂單確認流程
- 選 2：請用戶重新輸入客戶名稱
- 選 3：取消整個流程

### 模式 C：解析失敗

當系統無法理解訂單內容（confidence < 0.5）：

```
🤖 系統：
無法理解訂單內容。請提供：客戶名稱、品項和數量。
範例："/order 王小明 A產品x2 B產品x1"
```

## 品項格式

| 格式 | 範例 | 結果 |
|------|------|------|
| 品名x數量@單價 | `A產品x2@500` | A產品, 數量:2, 單價:500 |
| 品名x數量 | `A產品x2` | A產品, 數量:2, 價格:0（待補） |
| 數量+品名 | `2個A產品` | A產品, 數量:2, 價格:0 |
| 品名+數量 | `A產品 2` | A產品, 數量:2, 價格:0 |

**多品項：** 用逗號分隔，例如 `A產品x2@500, B產品x1@300`

**價格為 0 時：** 訂單會標記「待補價格」，可稍後在 ERP 系統中補填。

---

## 客戶比對邏輯

系統按以下順序比對 ERP 客戶：
1. 名稱完全匹配
2. 聯絡人完全匹配
3. 名稱部分匹配（包含關係）

---

## 錯誤回應

| 情況 | 系統回覆 |
|------|---------|
| 訊息無法解析 | 「無法理解訂單內容。請提供：客戶名稱、品項和數量。」 |
| ERP 無法連接 | 「無法連接 ERP 系統。請稍後再試。」 |
| 建立客戶失敗 | 「建立客戶失敗：{錯誤訊息}」 |
| 建立訂單失敗 | 「建立訂單失敗：{錯誤訊息}」 |
| Token 過期 | 自動刷新，用戶不會看到 |

## 快速記憶

- **觸發：** 用戶要「建立新訂單」
- **流程：** 解析 → 查客戶 → 確認 → 建立
- **狀態機：** 只有 `waitingForConfirmation` 和 `waitingForCustomerChoice`
- **成功後提示：** 建議用戶使用「生成報價單」功能
- **價格可選：** 品項可以不填價格，標記為 0 待補
- **成功回覆：** 提示使用 /pdf 指令出單，不包含 generate-pdf 的觸發詞
