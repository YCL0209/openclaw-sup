# Create Order - ERP 訂單建立系統

## 🤖 AI 調用指示（重要！）

### 何時調用
**立即調用此 skill** 當用戶訊息包含以下任一關鍵詞：
- 建立訂單、建單、創建訂單
- 下單、訂購、我要訂
- order、新訂單

### 如何調用
不需要等用戶說完整資訊，**立即啟動引導流程**。

### 第一句話
```
收到！開始建立訂單。

請提供 **客戶名稱**：
```

### 不要做的事
❌ 不要問「您想建立訂單嗎？」（用戶已經表達意圖）
❌ 不要等用戶提供完整資訊才開始
❌ 不要解釋這個 skill 是什麼（直接開始）

## 📋 標準互動流程

### 步驟 1：收集客戶名稱

**AI 問：**
```

```

**用戶回答：** `王小明`

**AI 行動：**
1. 查詢 ERP 客戶資料庫
2. 若找到 → 進入步驟 2
3. 若未找到 → 進入「新客戶流程」

### 步驟 2：收集品項和價格

**AI 問：**
```

**範例：**

  ABC電線x1@500, DEF開關x2@200
```

**用戶回答：** `ABC電線x1@500`

**AI 解析：**
- 品名：ABC電線
- 數量：1
- 單價：500

**AI 回覆：**
```
✅ 已記錄：ABC電線 × 1 @ $500
```

## 🎯 品項格式規則

### 支援格式

| 格式 | 範例 | 解析結果 |
|------|------|---------|
| **品名x數量@單價** | ABC電線x1@500 | 品名: ABC電線, 數量: 1, 價格: 500 |
| **品名x數量** | ABC電線x1 | 品名: ABC電線, 數量: 1, 價格: 0 |
| **多品項** | ABC電線x1@500, DEF開關x2@200 | 兩個品項 |

### 解析邏輯

```javascript
// 正則表達式
/([^x@,，]*?)x(\d+)(?:@(\d+))?/gi

// 範例
"ABC電線x1@500" → { name: "ABC電線", quantity: 1, price: 500 }
"ABC電線x1"     → { name: "ABC電線", quantity: 1, price: 0 }
```

## 🛠️ ERP API 集成

### 必需端點

| 端點 | 方法 | 用途 |
|------|------|------|
| `/api/auth/login` | POST | 認證取得 Token |
| `/api/customers` | GET | 查詢客戶列表 |
| `/api/customers` | POST | 建立新客戶 |
| `/api/orders` | POST | 建立訂單 |

### 認證流程

```javascript
// 1. 登入取得 Token
POST /api/auth/login
{
  "taxId": "00091103",
  "email": "info@sui-yao.com",
  "password": "******"
}

// 回應
{
  "success": true,
  "data": {
    "token": "eyJhbGci...",
    "expiresIn": 28800
  }
}

// 2. 後續請求使用 Token
Authorization: Bearer eyJhbGci...
```

### 建立訂單請求

```javascript
POST /api/orders
Authorization: Bearer <token>

{
  "orderType": "sales",
  "customerId": "697c1e6a0c8e65df3d13614e",
  "customerName": "王小明",
  "customerPhone": "0912345678",
  "items": [
    {
      "productCode": "ABC電線",
      "productName": "ABC電線",
      "quantity": 1,
      "unitPrice": 500
    }
  ],
  "paymentInfo": {
    "method": "cash",
    "isPaid": false,
    "paidAmount": 0
  }
}
```
