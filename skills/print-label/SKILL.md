# Print Label - 標籤列印

## AI 行為指引

### 何時啟動此 Skill
- 用戶要列印標籤、貼紙
- 關鍵詞：列印標籤、印標籤、印貼紙、print label
- 用戶指定要印的文字、品名、條碼

### 何時不要啟動
- 用戶要列印 PDF 文件（報價單/採購單）→ 應啟動 generate-pdf
- 用戶只是詢問標籤機狀態
- 用戶要建立訂單 → 應啟動 create-order

---

## 列印模式

### 模式 A：快速文字標籤
用戶直接指定文字內容，立即列印。支援用 `/` 分行。

```
📱 用戶：印標籤 藍牙耳機
🤖 系統：✅ 標籤已列印（1 張）

📱 用戶：印標籤 藍牙耳機/BT-001
🤖 系統：✅ 標籤已列印（1 張）— 2 行

📱 用戶：印標籤 藍牙耳機/BT-001/黑色
🤖 系統：✅ 標籤已列印（1 張）— 3 行
```

### 模式 B：帶條碼標籤
用戶指定品名和條碼，印出文字+條碼。

```
📱 用戶：印標籤 品名:藍牙耳機 條碼:BT-001
🤖 系統：✅ 標籤已列印（1 張）
        品名：藍牙耳機
        條碼：BT-001
```

### 模式 C：多張列印
用戶指定數量。

```
📱 用戶：印標籤 測試 x5
🤖 系統：✅ 標籤已列印（5 張）
        內容：測試
```

### 模式 D：產品標籤（查 ERP）
用戶指定品號，從 ERP 查詢產品資料後列印。

```
📱 用戶：印產品標籤 ABC-001
🤖 系統：✅ 標籤已列印（1 張）
        品號：ABC-001
        品名：藍牙耳機
```

## 錯誤回應

| 情況 | 系統回覆 |
|------|---------|
| 未提供內容 | 「請提供標籤內容。」+ 用法說明 |
| 印表機無法連線 | 「無法連接印表機服務，請確認 Windows 電腦和標籤機已開啟。」 |
| 列印失敗 | 「列印失敗：{錯誤訊息}」 |

## 常見錯誤（Anti-patterns）

- ❌ **不要** 在用戶說「列印報價單」「列印採購單」時啟動 — 那是 generate-pdf 的工作
- ❌ **不要** 在印表機離線時反覆重試 — 一次失敗後告知用戶檢查設備
- ✅ **一定要** 用 `/` 分行 — 「藍牙耳機/BT-001」是兩行標籤，不是路徑
- ✅ **一定要** 確認有標籤內容才發送列印 — 空內容時顯示用法說明
