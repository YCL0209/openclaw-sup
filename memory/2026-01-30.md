## 📚 重要知识点

### Skills vs Plugins
- **Skills** = 任务执行指令（如 create-order, generate-pdf）
  - 配置位置：`skills.entries`
  - 文件位置：`~/clawd/skills/`
  
- **Plugins** = 系统扩展功能（如 LINE channel）
  - 配置位置：`plugins.entries`
  - 不要混淆！

### SKILL.md 最佳实践
**关键部分：**
1. **Description** - 简洁明确（<100字），告诉 AI 何时调用
2. **AI 调用指示** - 明确第一句话、不要做的事
3. **结构化流程** - 步骤化对话模板
4. **错误处理模板** - 标准化错误消息
5. **快速参考卡** - AI 快速扫描用

### ERP API 集成架构
```
用户 LINE 消息
  ↓
Clawdbot Gateway (繁体中文界面)
  ↓
Skills (create-order, generate-pdf)
  ↓
ERP API (http://localhost:3000)
  - /api/auth/login - 认证
  - /api/customers - 客户管理
  - /api/orders - 订单管理
  - /api/orders/:id/pdf - PDF 生成
```

## 💡 经验教训

1. **Skills 应该用 .js 而非 .ts**
   - 除非项目需要强类型
   - .js 更简单，不需要编译

2. **SKILL.md 的 description 很关键**
   - 这是 AI 判断何时调用的依据
   - 必须包含触发关键词
   - 要简洁（<100字）

3. **用户语言很重要**
   - 台湾用户需要繁体中文
   - 所有用户可见文本都要本地化

4. **测试要在真实环境**
   - LINE 上的实际测试很重要
   - 发现了很多 CLI 测试发现不了的问题
