## 📚 重要知識點

### Skills vs Plugins
- **Skills** = 任務執行指令（如 create-order, generate-pdf）
  - 配置位置：`skills.entries`
  - 檔案位置：`~/clawd/skills/`
  
- **Plugins** = 系統擴充功能（如 LINE channel）
  - 配置位置：`plugins.entries`
  - 不要混淆！

### SKILL.md 最佳實踐
**關鍵部分：**
1. **Description** - 簡潔明確（<100字），告訴 AI 何時呼叫
2. **AI 呼叫指示** - 明確第一句話、不要做的事
3. **結構化流程** - 步驟化對話模板
4. **錯誤處理模板** - 標準化錯誤訊息
5. **快速參考卡** - AI 快速掃描用

### ERP API 整合架構
```
使用者 LINE 訊息
  ↓
Clawdbot Gateway (繁體中文介面)
  ↓
Skills (create-order, generate-pdf)
  ↓
ERP API (http://localhost:3000)
  - /api/auth/login - 認證
  - /api/customers - 客戶管理
  - /api/orders - 訂單管理
  - /api/orders/:id/pdf - PDF 生成
```

## 💡 經驗教訓

1. **Skills 應該用 .js 而非 .ts**
   - 除非專案需要強型別
   - .js 更簡單，不需要編譯

2. **SKILL.md 的 description 很關鍵**
   - 這是 AI 判斷何時呼叫的依據
   - 必須包含觸發關鍵詞
   - 要簡潔（<100字）

3. **使用者語言很重要**
   - 台灣使用者需要繁體中文
   - 所有使用者可見文字都要本地化

4. **測試要在真實環境**
   - LINE 上的實際測試很重要
   - 發現了很多 CLI 測試發現不了的問題
